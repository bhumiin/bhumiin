# Bhumin Desai

I build small, practical software for organizations that run on volunteers and spreadsheets.

- **Vidyapith Youth Day scoring** — scoring app for a volunteer-run Sunday school competition (12 grades, 3 judges per grade). Rebuilt a dead backend on Postgres, moved authentication into the database, closed a public API that exposed password hashes, and verified it with 69 policy tests and 25 independent security checks before event day.
- **Vidyapith app** — Flutter app for parents and students: class schedules, announcements, calendar.
- By day: application resilience and disaster recovery in a large regulated enterprise. I use AI coding agents for diagnosis, test harnesses and the parts nobody enjoys.

Most of what I build starts as a real annoyance someone I know has, and ends with something they can run without me.
